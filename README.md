# CS 19300 Final Project
This project is meant to be a simple tool to keep track of Splatoon match and tournament result data.

The most bare bones version of this should at least allow the user to easily write data into a file.

Schedule - (For V2.0+)
- Searching through data
- Tagging system
- Viewing data in groups through tags

Tech stack:
Java is the language I'm going to be using. As for libraries, everything that has to do with reading and writing objects, along with array lists, is what I'm going to need to use.
